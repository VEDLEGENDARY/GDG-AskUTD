Searching for Special Classes in
CourseBook
Go to CourseBook Search, check the box for include special classes and enter one of the following in
the search box:
note_llc = LLC Classes
note_archer = Archer Classes
note_cv = CV honors classes
note_ppf = Personal Program in Finance
