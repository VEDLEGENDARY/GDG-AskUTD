# PDF naming convention

Name each file after the page URL, without query parameters. Replace `:` and `/`
with `_`, replace `.` with `-`, and avoid other special characters.

`https://www.intel.com/content/www/us/en/support/intel-driver-support-assistant.html?updatenow`
becomes
`https___www-intel-com_content_www_us_en_support_intel-driver-support-assistant-html.pdf`

Use Ctrl+P (print to PDF) to save a web page. Download linked files too and name
them after their own links.
